# 工具评估记录

## 当前决定

首个里程碑不调用外部解包器。项目使用 Python 标准库自行读取 DAT1 目录表，以减少第三方可执行文件、覆盖行为和路径越界风险。解析器以二进制只读模式打开 DAT，并验证计数、压缩模式、偏移和大小边界。
