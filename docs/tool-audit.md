# 工具评估记录

## 当前决定

项目不调用外部解包器、反编译器或图像转换器处理游戏资源。当前使用 Python 标准库自行读取 DAT1、MSG、INT、FRM 和 PAL，并自行编码标准索引 PNG，以减少第三方可执行文件、覆盖行为和路径越界风险。解析器以二进制只读模式打开来源，并验证计数、偏移、大小和格式边界。
