## 边挖边记的约定

1. 开始一个新主题先在对应子目录建笔记，写清数据来源（资源路径 / 源码文件与函数 / 外部链接）。
2. 结论按证据分级：**已验证**（本机资源或源码直接读到）、**工具/外部推断**、**待人工确认**。
3. 脚本放 `scripts/`，派生产物放 `workspace/output/`，一起提交。
4. 攻略向结论同步到 Vault，并在笔记里注明写到了哪篇。
