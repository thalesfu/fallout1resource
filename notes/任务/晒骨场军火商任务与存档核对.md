# 晒骨场军火商任务与存档核对

日期：2026-09-18。用户问：Boneyard-08 存档里“递送军火商的包裹”为什么打完死亡爪母兽和蛋也没推进。攻略产出：Vault `07 游戏/辐射1/任务/Boneyard 晒骨场 - 军火商的死亡爪委托.md`。

## 结论

- 死亡爪委托（加布里尔）**不在 Pip-Boy 任务表里**，只靠 GVAR 614 `GUN_RUNNER` 与 265 号变量跟踪。
- “递送军火商的包裹”（PIPBOY.MSG 803）绑定 GVAR 129 `DESTROY_FOLLOWERS`，是**废弃内容**：没有脚本把它设为 1，公事包（item PID 72）不在任何地图上、也没有脚本生成。
- Boneyard-08：614 = 9201（已接未交），265 = 9250（清巢完成），129 = 0。回去找加布里尔对话即可结算。

`talk_p_proc`：`614 == 9201 && 265 == 9250` → 交任务对话；只有 `614 == 9201` → 等几天的对话。

## 方法

1. 日志文本号 → 引擎任务表：`701 + 10 × 地点 + 序号`（`pipboy.cc`），晒骨场是第 10 个地点。
2. GVAR 名字要按 VAULT13.GAM 注释里的 `(N)` 取，**按行数数会错位**（文件里有多余行，601 以后全部偏移）。
3. 存档：0x7563 字节文件头 + 4 字节 dude CID，之后是全部 GVAR（大端 int32），见 `scripts/read_save_gvars.py`。
4. 在全部反汇编里搜 `push_int <变量号>` 后跟 `global_var` / `set_global_var` 定位读写者。赋值表达式较长时要把窗口放大，否则会漏掉。
