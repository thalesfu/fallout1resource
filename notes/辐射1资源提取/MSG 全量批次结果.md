# MSG 全量批次结果

日期：2026-07-28（批次清单使用 UTC 时间）

## 已验证结论

使用 `fallout1resource 0.3.2` 处理 `MASTER.DAT` 与松散 `DATA/` 的全部非存档 MSG。DAT 资源先只读提取，松散资源直接只读转换；派生物均写入工作区。游戏安装目录未发生写入。

| 项目 | 结果 |
|---|---:|
| DAT 选择 / 成功 / 结构失败 | 1,950 / 1,944 / 6 |
| DAT 源容量 / 派生写入 | 6,276,495 / 约 63.2 MB |
| 松散 DATA 选择 / 成功 / 结构失败 | 649 / 635 / 14 |
| 松散源容量 / 派生写入 | 3,501,708 / 39,324,512 字节 |
| DAT 断点复跑：校验后跳过 / 失败 | 1,944 / 6 |
| DATA 断点复跑：校验后跳过 / 失败 | 635 / 14 |

DAT 提取清单为 `workspace/manifests/extraction-20260727T223334875565Z.json`。最终 0.3.2 DAT 断点清单为 `batch-msg-20260727T234420444992Z.json`，松散 DATA 断点清单为 `batch-msg-20260727T234319341530Z.json`。

全量运行发现通用编码启发式会把少量官方法文/西班牙文高位字节误判为 CJK。0.3.2 对官方 `master` 来源固定采用可逆 Latin-1，对实际包含中文汉化的松散 `data` 继续自动检测。修正后 DAT 成功数由 1,941 提升到 1,944。

## 原始文件异常

DAT 的 6 个真实结构异常如下，均保留在批次清单中，没有修改或猜测补齐：

- 字段数不是三的倍数：英/法/西班牙文 `OBJ_DUDE.MSG`，西班牙文 `MORPH.MSG`、`NICOLE.MSG`。
- 无效消息编号：西班牙文 `DARL.MSG`。

松散 DATA 的 14 个异常为：分隔符不匹配 5 个，字段数异常 7 个，无效编号 1 个，空编号 1 个。具体文件和行号见最终批次清单。一次 `BITSBOB.MSG` 输出曾被 Windows/iCloud 短暂占用；单文件重试成功，因此不计为最终失败。

**工具推断：** 与 Fallout Community Edition 的 `message_load_field`、`message_load` 和 `message_parse_number` 逐项核对后，这些写法也不符合游戏加载器规则，应视作发行资源中的未使用内容或原始缺陷，而不是解析器兼容性遗漏。

## 抽查与统一索引

DAT 成功输出包含 106,009 条记录，39 个文件存在重复编号；全部 1,944 个元数据均标记为显式 ISO-8859-1。松散 DATA 成功输出包含 67,466 条记录，619 个文件存在重复编号；538 个为中等置信度 GBK、85 个为低置信度 GBK，其余为 ASCII、Latin-1 或 GB18030。抽查 CSV 的独立 SHA-256 与 JSON `derived.csv` 一致。

统一索引将在所有格式全量批次完成后统一重建；此前 0.3.0 的索引数字仅保留为阶段历史，不代表当前最终状态。
