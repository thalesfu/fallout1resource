# 《辐射 1》资源提取项目导航

这是工程的首要入口。代码位于 `C:\Users\Thales\codes\github.com\thalesfu\fallout1resource`；本目录只保存设计、操作方法和研究结论，不保存游戏资源或大体积派生文件。

## 开始工作

1. 先看 [[资源提取设计方案]]，确认范围、目录职责和只读原则。
2. 实际操作照 [[安全运行手册]] 执行，所有转换先 dry-run。
3. 当前进度和未完成项看 [[工作计划 Checklist]]。
4. 遇到异常先查 [[经验总结与待决策]]，不要在源目录试错。
5. 自动化全量结果看 [[全量交付与验收结果]]；剩余主观检查看 [[全量人工抽查表]]。

环境基线：[[本机游戏版本与补丁基线]]

## 当前能力矩阵

| 资源 | 命令 | 当前能力 | 代表样本 | 本地提交 |
|---|---|---|---|---|
| DAT1 清单 | `inventory` | 清点 DAT 与松散 `DATA/`，排除存档，记录来源和哈希 | `MASTER.DAT`、`CRITTER.DAT` | `00bf37f` |
| DAT1 提取 | `extract` | 精确路径/类型筛选，支持 `0x20` 与 `0x40`，默认 dry-run | `HAROLD.MSG` | `5b6da57` |
| MSG | `convert-msg` / `convert-msg-batch` | 编码检测、重复编号保留、可恢复全量 JSON/CSV 批处理 | 1,950 个 DAT MSG | `a8b06c2`、`6589c73` |
| INT | `disassemble-int` / `disassemble-int-batch` | 979 个全量结构化反汇编、有效来源 MSG 关联；不执行脚本 | 全部 DAT 与松散 INT | `678fddc`、`b001917` |
| FRM/PAL | `convert-frm` / `convert-frm-batch` | 10,439 项全量 PNG、共享/分方向帧与可恢复哈希复跑 | 全部 DAT 与松散图像 | `ba40325`、`3f38d5e` |
| MAP/PRO/LST | `convert-map` / `convert-map-batch` | 72 个地图全量对象树及 PID—LST—PRO 链路、依赖哈希复跑 | 全部原版地图 | `d21dce6`、`a378c51` |
| ACM | `convert-acm` / `convert-acm-batch` | 2,530 个全量无损 PCM WAV、末块兼容审计与哈希复跑 | 全部 DAT 与松散 ACM | `5817cb2`、`e44cbae` |
| MVE | `convert-mve` / `convert-mve-batch` | 13 个全量原生检查；恢复显示时间轴，固定 FFmpeg 输出 PNG/WAV/MP4 并哈希复跑 | 全部 DAT MVE | `738f08e`、`8d3fc8a`、`df2120a` |
| 统一索引 | `build-index` | inventory、提取和转换记录 → 主表、派生、失败、冲突、批次与组合哈希 | 26,111 条资源 | `abd08a7` |

当前自动测试基线为 156 项通过、7 项因 Windows 无符号链接权限而跳过。Ruff 0.15.22 格式与静态检查通过。跳过项不是功能失败，但在支持符号链接的环境中仍需补跑。
