## 战斗公式要点（已写进 Vault）

- 命中率按固定顺序累加，上限 95%、**无下限**；战斗难度只影响 NPC 打玩家。
- 距离修正：`距离 − 2×感知`（长程武器 4×感知），超出每格 −4%，以内每格 +4%（上限 +8×感知）。
- **省下的 AP 在别人回合会全额加进自己的 AC**（`stat_level`）。
- 暴击率基础值 = 幸运；瞄准部位的暴击加成等于命中惩罚的绝对值，**连发不吃这个加成**。
- **游戏内时间不满 1 天时，掷骰式大成功/大失败完全不触发**（`roll.cc`），而游戏从 12-05 07:21 开始。
- 伤害逐发结算：`(武器伤害 + 远程加成) × 暴击倍率 × 难度 − DT`，再扣 DR%。
- **F1 不读弹药的 AC/DR 修正与伤害倍率**（字段只在 proto 读写处出现），弹种只决定口径。
- 派生属性：HP `15+ST+2×EN`、AP `AG÷2+5`、AC `AG`、序列 `2×PE`、暴击率 `LK`、治疗 `max(EN÷3,1)`。
- AI 逃跑用**绝对生命值** `min_hp`，不是百分比；换目标按 `max(近战伤害, 武器最大伤害) + AC` 排序。

## 脚本端 Perk（本轮解出）

- **意志力**：`REVULSE.INT` 每段造成 `随机(1, 感知)` 点无视护甲伤害并逐段累加，队友按各自感知同样受伤；有 Perk 则整段跳过。**感知越高伤害越高**。
- **动物之友**：辐射蝎与老鼠脚本在 `obj_can_see_obj(自己, 玩家)` 后判断，有 Perk 就不发起攻击。
- **野外专家**：遭遇脚本把等级存进计数器，掷到敌对遭遇类型（1/2/3/4/7）时把类型改成 0 并把计数器减 1，即每级取消一次敌对遭遇。
- **警觉力**：18 个角色脚本在 `description_p_proc` 里做 `do_check(玩家, 感知, 有无此 Perk)`，通过后显示额外描述文本。
- **搜寻者**：`RNDDESRT` 中有 Perk 时 `create_object_sid(34)`（.223 FMJ）并放进物品栏。

## 踩坑

- catalog 里的 `kill_type` 存的是数字 id，而暴击表和族群表按名字索引，两边要显式换算。
- 地图 JSON 的库存条目键名是 `item`，不是 `object`。
- **生成器扫描“已有笔记”时必须排除自己上一轮的产物**，否则第二次运行会把原型页当成已有笔记，往自己身上再追加一遍战斗资料块。已用文件名的“（原型 N）”后缀排除。
- Vault 里的物品笔记同样带 `prototype_id` 字段，匹配生物时要限定在 `人物/` 与 `生物/` 目录下。
- `create_object_sid` 的 PID 是最先压栈的参数，在反汇编里要取调用前的**倒数第 4 个**字面量，取最近的会拿到 tile 或 elevation。

## 连发机制细节（2026-09-30 补，`compute_spray` / `shoot_along_path`）

- 弹数 = `min(当前弹匣, 武器 rounds)`，弹匣不满也能连发。
- 先掷一次 `roll_check(命中率, 暴击率)`：大失败整轮终止（子弹仍消耗）；大成功让后续每发 +20 命中。
- 分路：`中路 = 弹数 / 3`（至少 1），`左路 = 弹数 / 3`，`右路 = 弹数 − 中路 − 左路`；`主目标 = 中路 / 2`，为 0 时取 1 并 `中路 -= 1`。
- 主目标逐发 `roll_check(命中率, 0)`；若 0 发命中则 `check_ranged_miss` 可补记 1 发。
- 中路剩余沿 `tile_num_beyond(自己, 目标, 射程)` 的延长线走 `shoot_along_path`：对路径上每个生物用其自身 `determine_to_hit_func`（躯干、忽略距离）做 `while roll_random(1,100) <= accuracy && 剩余弹数 > 0` 的连扣循环。
- 左右两路：中心点取目标（距离 ≤ 3 时取目标后方 3 格），分别朝 `(rotation+1)%6`、`(rotation+5)%6` 偏 1 格取线。
- 旁人记入 `extras`，上限 6，按躯干、倍率 2 单独 `compute_damage`；同一人被多路命中时连发会累加伤害。
- 结果改写：初掷失败但有人中弹 → 成功；初掷成功但无人中弹 → 失败。
- 连续射击（火焰喷射器）：左/中/右/主目标各 1 发，`shoot_along_path` 中 `remainingRounds` 每个生物重置为 1，且函数末尾把主目标命中数归零（`anim == ANIM_FIRE_CONTINUOUS`）。
- 伤害在 `compute_damage` 中按发循环，**每发单独减 DT 再扣 DR%**，因此连发对高伤害阈值目标效率极差。

## 死亡动画与战利品（2026-09-30 补，`actions.cc`）

- `pick_death`：单击伤害 ≥ 45 或带 Bloody Mess 且暴力等级 > NORMAL → `death_3[damage_type]`；伤害 ≥ 15 且暴力等级 > MINIMAL → `death_2[damage_type]`；否则倒地。美术缺失时 `check_death` 回退到 `death_2`。
- `death_3` = 血肉横飞(普通)、切成两半(激光)、火焰之舞(火焰)、**融化 MELTED_TO_NOTHING(等离子)**、电解消失(电击)、倒地(EMP)、炸碎(爆炸)。
- `show_death`（actions.cc:417）只在 `ANIM_ELECTRIFIED_TO_NOTHING(30) ≤ anim ≤ ANIM_EXPLODED_TO_NOTHING(31)` 时调用 `item_drop_all`。
  - **`ANIM_MELTED_TO_NOTHING` 是 32、`ANIM_BURNED_TO_NOTHING` 是 29，都不在区间**：等离子融化与火焰烧尽会让尸体连同全部随身物品一起消失，玩家拿不到任何战利品。
  - 电击消失与爆炸粉碎则会把物品掉在地上。
- 护甲对等离子的防御两极：皮装甲 0/10%、皮夹克与长袍 0/10%（比普通伤害还弱），而战斗装甲 4/50%、兄弟会装甲 7/60%、德斯拉装甲 10/80%。

## 休息机制（2026-09-30 补）

- `critter_can_obj_dude_rest`（critter.cc:1162）：先按地图选 `check_team`——HUBOLDTN、HUBHEIGT、LARIPPER、LAGUNRUN、V13ENT 为 true；CHILDRN1 与 HALLDED 非 0 层为 false；否则按城镇，Vault 13／沙荫镇／迦克镇／哈勃城／兄弟会／**晒骨场**为 false，其余城镇为 true。
- 然后遍历同层所有活着的生物：任一生物的 `whoHitMe == obj_dude` 直接禁止休息；`check_team` 为 true 时，存在任何与玩家不同队的活人也禁止。
- 回血：`pipboy.cc` `AddHealth` 每 3 小时调用 `partyMemberRestingHeal(3)`，party.cc 中 `v1 = 小时/3`，每名成员恢复 `v1 × STAT_HEALING_RATE`；`partyMemberList[0]` 就是玩家，所以玩家同样按自己的治疗速率回血。世界地图旅行处调用的是 `partyMemberRestingHeal(24)`。
- `MAP_CAN_REST_ELEVATION_*` 标志只在 worldmap.h 定义，F1 代码里没有引用，实际判定完全走上面的函数。
