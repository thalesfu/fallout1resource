# 人物位置图生成与裁切规范

本文记录人物资料页和区域资料页所用地图的生成方法。游戏资料页只嵌入最终地图；提取、标注和裁切规则集中保存在本工程文档及资源仓库的 docs/map-rendering.md 中。

## 数据来源

以资源仓库 fallout1resource 的地图渲染结果为只读输入：

| 输入 | 用途 |
|---|---|
| 无标注完整合成图 | 作为地图底图 |
| 人物透明层 | 生成所有人物的轮廓 |
| 物品透明层 | 区域总图生成可获取物品与容器轮廓 |
| 人物与物品元数据 JSON | 提供地图对象 ID、名称、锚点和标签框坐标 |

人物必须按地图对象 ID 选取，不能只按名称选取。普通人物可能重名，同一人物原型也可能被多个地图对象复用。

## 人物资料页位置图

1. 在无标注完整合成图上叠加人物透明层。
2. 对人物非透明像素向外扩张2像素，再减去原始人物掩码，得到不覆盖人物造型的轮廓。
3. 所有人物使用亮绿色，RGB 为 101、231、101。
4. 根据目标人物的地图对象 ID，从元数据中取得 target_canvas 锚点。
5. 在锚点附近选择最近的人物像素连通区域，将目标人物改为3像素橙色轮廓；橙色 RGB 为255、126、48。
6. 普通人物的引线和标签框继续使用绿色；目标人物的引线和标签框使用橙色。
7. 标签文字和位置直接复用元数据中的 display_name、target_canvas 和 label_box_canvas。
8. 人物资料页不绘制物品轮廓、物品标签或容器清单。
9. 完成标注后再裁切活动区域，同时保留未裁切版本。

缺失人物 FRM 时，只能保留名称锚点，不能伪造或借用其他人物造型。

## 旧城区哈罗德实例

| 项目 | 值 |
|---|---|
| 地图 | HUBOLDTN |
| 楼层 | 0 |
| 完整画布 | 6656×3326 |
| 焦点人物 | Harold 哈罗德 |
| 地图对象 ID | 1633 |
| 人物页裁切框 | 左1750、上1000、右4650、下2450 |
| 裁切结果 | 2900×1450 |
| 普通人物颜色 | RGB 101、231、101 |
| 哈罗德颜色 | RGB 255、126、48 |

输出文件：

- 地点/Hub 哈勃城/Old Town 旧城区/人物/attachments/Old Town 旧城区地图（人物标注，哈罗德高亮）.png
- 地点/Hub 哈勃城/Old Town 旧城区/人物/attachments/Old Town 旧城区地图（人物标注，哈罗德高亮，活动区域裁切）.png

## 区域总图

区域总图同时保留人物、可获取物品、容器和地图外对象标注。裁切时可以去掉完整画布左右及下方的冗余区域，但必须保留地图格0物品、地图外交易库存箱，以及渲染器已经生成的引线和标签框。

旧城区区域总图采用以下规则：

| 项目 | 值 |
|---|---|
| 裁切框 | 左1750、上0、右4650、下2450 |
| 裁切结果 | 2900×2450 |
| 人物标签 | 30个 |
| 活动区域物品或容器标签 | 7个 |
| 地图外对象标签 | 地图对象25、26、27、28、163 |

对象25、26、27是地图格0的三件火焰喷射器；对象28和163是地图外交易库存箱。为了保留它们的原始锚点、引线和标签框，区域总图从完整画布顶部开始裁切。这些对象仍需在资料页表格中以警告或删除线注明其处于正常活动边界之外。

区域总图输出：

- 地点/Hub 哈勃城/Old Town 旧城区/attachments/Old Town 旧城区地图（人物与物品标注，活动区域裁切）.png

## 裁切规则

- 裁切坐标以完整渲染图左上角为原点。
- 裁切应在轮廓、引线和标签绘制完成后进行。
- 必须完整保留正常活动道路、建筑、可见人物和标签框。
- 区域总图必须保留地图外交易库存、地图格0对象及其已有标注；人物资料页则只保留人物标注。
- 不直接覆盖完整来源图；裁切版使用独立文件名。
- 不同地图和楼层必须分别确定裁切框，不能照搬旧城区坐标。

## Obsidian 附件规则

- 图片放在与使用笔记最近的 attachments 目录中。
- 笔记使用 Obsidian 图片嵌入，不写本机绝对路径。
- 文件名应说明地图、标注内容、焦点人物和是否裁切。
- 人物页默认嵌入宽度为900像素；完整分辨率保留在附件文件中。

## 验收清单

- [ ] 普通人物均为绿色。
- [ ] 焦点人物的轮廓、引线和标签框使用另一种颜色。
- [ ] 焦点人物按地图对象 ID 选中。
- [ ] 人物页没有物品或容器标注。
- [ ] 区域总图完整保留地图外对象、引线和标签框。
- [ ] 裁切没有切断正常人物、建筑、引线或标签框。
- [ ] 完整图与裁切图均可恢复和追溯。
- [ ] Obsidian 嵌入可以正常显示。
