# 地图人物对象 ID 核对方法与哈勃城执行记录

## 目的

本方法用于把地点笔记中的每一行人物，与游戏地图导出数据中的具体人物对象逐一对应。最终写入地点笔记的是“地图对象 ID”，人物身份仍以游戏脚本、对话和人物原型为依据。

## ID 的含义

“地图对象 ID”来自对应 `.MAP` 的对象记录，可用于定位该地图中的具体人物。它不是人物原型 ID，也不是脚本 ID。

> [!important] ID 不是跨地图的全局编号
> 不同地图可以出现相同的地图对象 ID。核对和引用时应使用“地图名 + 楼层 + 地图对象 ID”这一组合，例如 `HUBDWNTN / elevation 1 / 1598`。地点笔记已经按区域分节，因此表格中只显示地图对象 ID。

## 逐对象人物笔记的命名

同一地图中的普通人物即使类别相同，也应逐对象建立笔记，并在文件名中写入地图对象 ID：

```text
地点英文名 中文名 - 英文人物名 中文人物名（ID 地图对象ID）.md
```

例如：

```text
Hub 哈勃城 - Vance 万斯（ID 654）.md
Hub 哈勃城 - Police 警察（ID 46）.md
Hub 哈勃城 - Police 警察（ID 178）.md
```

文件名中的 `ID` 均指地图对象 ID。笔记属性中同时记录 `map`、`elevation`、`map_object_id`、`prototype_id`、`map_tile` 和可用的 `resource_script`，避免把地图对象 ID 与人物原型 ID 混用。普通类别名不建立无编号别名，以免多个“警察”或“农民”页面产生歧义。

## 使用的导出字段

人物标注元数据位于资源仓库的 `workspace/output/maps-rendered/<地图名>/` 中。

| 字段 | 用途 |
|---|---|
| `object_id` | 写入地点笔记的地图对象 ID。 |
| `tile` | 核对人物在地图上的位置，排查同名对象。 |
| `prototype_list_index` | 人物原型 ID；无独立脚本的人物尤其需要此字段。 |
| `script_filename` | 最可靠的专名人物线索之一，可继续关联脚本和对话文件。 |
| `source_name` | `PRO_CRIT.MSG` 提供的原型显示名，常用于普通人物类别。 |
| `display_name` | 标注图采用的最终名称，可用于快速核对，但不能替代脚本和原型证据。 |

## 人物身份的核对顺序

1. 先按区域确定地图名和楼层，不能只拿对象 ID 在全部地图中搜索。
2. 从人物标注元数据取得该对象的 `object_id`、`script_filename` 和 `prototype_list_index`。
3. 有专用脚本时，优先用脚本文件名关联已导出的脚本和英文对话 `MSG`；自我介绍、查看描述和其他明确台词可确认规范英文名。
4. 没有专用脚本时，检查人物原型。若技术资料能够把专名与原型唯一对应，再把专名落到地图对象上。
5. 只有类别名、共用脚本或共用原型时，保留“警察”“警卫”“农民”等普通人物名称，不强行添加专名。
6. 同类人物必须逐对象列行，每行只写一个地图对象 ID；不能把多个对象合并成一个数量。
7. 最后比较人物表中的 ID 集合与地图导出人物对象集合，确认数量、唯一性以及缺失项完全一致。双头牛等非人物生物应在比较前排除。

## 容易混淆的情况

### 标注图显示类别名，不等于无法确认身份

标注图可能只显示人物原型的类别名。例如万斯身边的两个人在旧城区标注图上都显示为“暴徒”，但地图对象仍保存了不同的人物原型：

| 地图对象 ID | 人物原型 ID | 最终身份 |
|---:|---:|---|
| 541 | 238 | Justin 贾斯廷 |
| 790 | 246 | Chad 查德 |

万斯的对话 `VANCE.MSG:130` 明确说两人是 Justin 和 Chad；辅助技术资料分别把 Justin 对应到原型 `238`、Chad 对应到原型 `246`。因此两者可以逐一落到对象 `541` 和 `790`，不能仅因二者都没有独立脚本而写成“无法区分”。参考：[Justin 技术资料](https://fallout.fandom.com/wiki/Justin_%28Fallout%29)、[Chad 技术资料](https://fallout.fandom.com/ru/wiki/%D0%A7%D0%B0%D0%B4_%28Fallout%29)。

### 同名人物可能不是同一个人

- 中心区对象 `2505` 是 `Justin.int` 对应的警长 Justin Greene 贾斯丁·格林。
- 旧城区对象 `541` 是万斯的守卫 Justin；现有游戏台词只提供名字 Justin，不能把警长的姓氏 Greene 移植给他。

### 同一人物可能在不同地图有不同对象

- Tony Fry 托尼·佛莱在城门是对象 `1311`，在德克藏身处是对象 `2540`。
- Rutger 罗格尔在中心区是对象 `937`；旧城区对象 `1124` 使用罗格尔原型，但执行绑匪看守脚本，应同时说明当前地图中的实际作用。

## 后续地区的验收清单

- [ ] 每个区域已经对应到明确的地图名和楼层。
- [ ] 每个人物行都有地图对象 ID。
- [ ] 专名人物已检查脚本文件名和对话来源。
- [ ] 无脚本专名人物已检查人物原型，不按视觉顺序猜测。
- [ ] 普通人物保持逐对象列行，没有按数量合并。
- [ ] 同名人物已检查是否属于不同角色或不同地图实例。
- [ ] 已排除非人物生物，再比较表格与导出数据。
- [ ] 表格中的 ID 数量、唯一数和导出对象集合完全一致。
